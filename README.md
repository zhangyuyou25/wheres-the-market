# Where's the Market · 外资超市分布查询

把**山姆（Sam's Club）、开市客（Costco）、奥乐齐（ALDI）**三家纯外资超市在中国大陆的门店地址整理在一起，按城市/行政区分类，支持搜索和标签筛选，一次看全。

## 使用方式

直接打开 `index.html` 即可使用，无需安装任何依赖。

在线访问：https://zhangyuyou25.github.io/wheres-the-market/

## 功能

- **搜索框**：输入城市名、区名或门店名（如"静安"、"上海"、"奥乐齐"）
- **品牌标签**：点击筛选山姆 / 开市客 / 奥乐齐，支持多选
- **地区标签**：点击筛选城市（上海、苏州、北京……），支持多选
- **按区分组展示**：结果按城市 → 行政区分组，显示门店名称、详细地址和营业时间

## 数据概况

| 品牌 | 母公司 | 总部 | 数据来源 |
|------|--------|------|----------|
| 山姆 Sam's Club | 沃尔玛 Walmart | 美国 | 山姆会员商店官网 |
| 开市客 Costco | Costco Wholesale | 美国 | 开市客中国官网 |
| 奥乐齐 ALDI | ALDI Süd | 德国 | 奥乐齐中国官网 |

## 收录标准

- **纯外资超市**：母公司总部在中国大陆以外
- **实体门店**：有线下实体店铺，非纯线上
- **面向个人消费者**：非批发/餐饮供应链

目前收录山姆、开市客、奥乐齐三家。

**沃尔玛购物广场**：官网无门店查询功能，数据无法验证，暂不收录。
